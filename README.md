# Clash Verge Rev Stable Builds

Download the x64 or ARM64 installer from the [latest Windows release](https://github.com/vertno/clash-verge-rev/releases/latest). The original desktop update control checks this repository. The original core update control checks the [personal Mihomo releases](https://github.com/vertno/mihomo/releases/latest).

The original Mihomo and Mihomo Alpha choices both use the same verified personal stable build. Each keeps its original executable name and update control. Updates use the personal Tauri signing key. The release tag contains the patched source and its dependency record. The `distribution` branch holds the patch and release workflow. [Official Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)
